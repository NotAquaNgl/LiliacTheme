### 🔧 Technical Details

- **Dynamic class matching**: Uses `[class*="name_"]` attribute selectors for Discord compatibility
- **Performance optimized**: No heavy filters, minimal repaints
- **GPU-accelerated**: Uses transform and opacity for smooth animations
- **Lightweight transitions**: 0.1s-0.4s durations, no infinite animations

---

### 📦 Installation

1. Copy `Lillac-V3.0.7.theme.css` to your Vencord themes folder
2. Enable the theme in Vencord settings
3. Reload Discord (Ctrl+R)

**Vencord themes folder:**
```
%AppData%\Vencord\themes\
```
